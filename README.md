# 바탕화면 치이카와

창이 뜨면 치이카와·하치와레·우사기·모몽가가 화면 아래에서 뿅 튀어나와 창 위에 올라섭니다.
창 위를 돌아다니고, 옆 창으로 뛰어 건너가고, 창을 옮기면 같이 실려 가고, 창을 닫으면 떨어집니다.

- 맥 전용 (Swift + WKWebView, 앱 크기 0.6MB)
- 권한 필요 없음 · 클릭은 전부 밑의 앱으로 통과
- `⌥⇧K` 숨기기/보이기 · 메뉴바에서 마리 수·크기 조절

```bash
npm install
npm start
```

> 개인용 팬아트입니다. 캐릭터는 나가노(ナガノ)의 「치이카와」 캐릭터를 도형으로 따라 그린 것입니다.
