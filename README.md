# 바탕화면 치이카와

창이 뜨면 치이카와·하치와레·우사기·모몽가·쿠리만쥬·랏코·시사가 화면 아래에서 뿅 튀어나와 창 위에 올라섭니다.
창 위를 돌아다니고, 옆 창으로 뛰어 건너가고, 창을 옮기면 같이 실려 가고, 창을 닫으면 떨어집니다.

- 맥 (Swift + WKWebView, 0.7MB) · 윈도우 (.NET + WebView2) — 윈도우판은 아직 실제 PC 에서 확인 전
- 모니터가 여럿이면 모든 모니터에 산다 · 윈도우에서 창을 최대화하면 작업 표시줄 위에 선다
- 권한 필요 없음 · 클릭은 전부 밑의 앱으로 통과
- `⌥⇧K` (윈도우 `Alt+Shift+K`) 숨기기/보이기 · 메뉴바에서 마리 수·크기 조절
- 메뉴바 → 「캐릭터 그림 폴더 열기」에 그림(`chiikawa.png` 처럼 이름 붙여서)을 넣으면 그 그림으로 나옵니다

```bash
npm install
npm start
```

> 개인용 팬아트입니다. 캐릭터는 나가노(ナガノ)의 「치이카와」 캐릭터를 도형으로 따라 그린 것입니다.
