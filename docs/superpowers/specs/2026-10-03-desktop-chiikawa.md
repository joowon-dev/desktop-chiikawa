# 바탕화면 치이카와 — 첫 판 스펙 (2026-10-03)

## 요청 (원문)
> 치이카와 캐릭터들이 창이 생기면 화면에서 나와서 창마다 상단에 치이카와 캐릭터들이 배치가 되는거야 !!!
> 나 잘 거니까 너가 알아서 만들어줘. 캐릭터들은 창 위를 마음껏 돌아다닐 수 있어.

주인이 자는 동안 만들었으므로 질문 없이 아래를 정했다. 바꾸고 싶으면 여기부터.

## 정한 것
| 질문 | 정한 답 | 이유 |
|---|---|---|
| 「화면에서 나온다」 | 화면 **아래 가장자리에서 솟아올라** 창 윗변 70px 위까지 떴다가 내려앉는다 + 반짝이 | 어느 창이든 같은 동작, 가장 「튀어나온」 느낌 |
| 창마다 몇 마리 | 새 창마다 하나. 보이는 창 수만큼(최소 둘), 최대 8(메뉴로 1~12) | 창이 20개면 20마리는 시끄럽다 |
| 누가 나오나 | 치이카와·하치와레·우사기·모몽가, 적게 나온 아이부터 | 네 아이가 고루 |
| 그림 | 공식 이미지 없이 캔버스 도형 | 저작권 · 앱 크기 · 크기 조절 |
| 돌아다니기 | 걷기·앉기·자기·제자리 뛰기·말풍선·옆 창으로 점프·창 끝에서 뛰어내리기·붙어 서면 같이 신남 | 「마음껏」 |
| 가려진 창 | 앞 창에 가린 부분은 안 보이게 그리고, 거기로는 안 걷는다. 다 가려지면 4 초 뒤 보이는 창으로 | 창 「위」에 있다는 느낌 |
| 창 이동·닫기 | 같이 실려 가며 휘청 / 떨어져서 밑의 창에 착지하거나 화면 밖으로 | |

| 플랫폼 | 맥 먼저. 윈도우는 열린 일 | 이 맥에서 검증할 수 있는 것만 |
